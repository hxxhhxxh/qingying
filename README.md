## 这是什么

一个可交互的产品原型，演示「收入到账 → 自动分账 → 悦己额度 → AI 体检与调剂 → 目标与规则共创」的完整链路。

打开页面后：

1. 首页看到本月到账 ¥3,200 被分成 **悦己 / 成长 / 安全 / 未来** 四份。
2. 点「一键快乐分账」看四账户入账动画。
3. 点「让 AI 管家看看」：AI 把你的悦己余额换算成“还能喝 22 杯奶茶”，并提示买手办会超支 ¥160。
4. 点「确认调剂 ¥160」：AI 只提建议，调剂由本人确认，安全账户与未来账户一分不动。
5. 点「看看我的攒钱目标」：目标进度、悦己权益、下季度比例的**用户投票**。

## 产品观

> 理财不是让你少喝奶茶，而是让你知道**这个月还能喝几杯**。

生活费、奖学金、兼职与实习收入，构成了我们这代人的第一笔可支配收入。问题不是钱不够，而是钱没有结构：月初到账、月末见底。青盈把“分配”这件事变成一次授权、一个比例、四个账户。

## 数据依据

- 2025 年在校大学生月均生活费 **1744 元**，较 2016 年（1212 元）增长 **43.9%**，高于同期 CPI 累计涨幅；71.7% 的受访学生表示生活费能满足甚至略超出日常需求 —— 麦可思《2025 年在校大学生消费行为研究》（2783 名在校生样本）。
- 持有金融资产 5000 元以上的大学生占比达 **29.60%**，接近上一报告期的两倍 —— 国泰基金《第四期全国大学生财富素养调查》（覆盖全国近百所高校）。

## 技术说明

- 纯静态单文件：`index.html`，零依赖、不联网、不收集任何数据。
- 原型中的分账与 AI 对话为**可解释的规则演示**；正式方案中大模型只负责解释与建议，资金动作全部由规则引擎执行并经本人确认。

## 合规声明

原型不采集、不上传、不存储任何用户输入；页面中的金额、姓名与目标均为示例数据。正式产品设计不做收益承诺、不推荐投资标的。
